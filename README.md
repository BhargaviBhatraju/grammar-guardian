# Grammar Guardian

An AI-powered Grammar Correction framework using T5 and JFlEG dataset
---
##  Project Overview

Grammar Guardian is a Natural Language Processing (NLP) based web application that improves the quality of English writing by automatically correcting grammar mistakes. The application uses a pre-trained Transformer model to generate grammatically correct sentences while providing a responsive web interface for users.
##  Features

- AI-powered grammar correction
- Transformer-based T5 language model
- Real-time sentence correction
- Responsive user interface
- Flask backend
- REST API integration
- Word count and character count
- Error handling and logging
- Easy deployment with Render

## Technologies Used
### Backend
- Python
- Flask
- Hugging Face Transformers

### Frontend

##  Installation

### Clone the Repository

```bash
git clone https://github.com/BhargaviBhatraju/grammar-guardian.git
cd grammar-guardian
```
### Install Dependencies

```bash
pip install -r requirements.txt
```
### Run the Application

```bash
python app.py
```
Open your browser and visit:

```
http://127.0.0.1:5000
```

---
##  Workflow

1. Enter an English sentence.
2. Click **Correct Grammar**.
3. The Flask backend sends the sentence to the T5 grammar correction model.
4. The model generates the corrected sentence.
5. The corrected output is displayed on the webpage.
