About the Project

Grammar Guardian is an AI-powered grammar correction web application developed using Python Flask and the Hugging Face Transformers library. The system helps users automatically identify and correct grammatical mistakes in English sentences.

Project Features

  • Grammar Correction using Artificial Intelligence
  • Fast and Accurate Sentence Correction
  • Responsive User Interface
  • Real-Time Grammar Checking
  • Flask Backend Integration
  • Easy Deployment using Render

Technologies Used

  • Python
  • Flask
  • HTML5
  • CSS3
  • Hugging Face Transformers
  • T5 Grammar Correction Model

Dataset

The grammar correction model is based on datasets commonly used for Grammar Error Correction (GEC), including JFLEG-style sentence correction tasks.
